Regras de conclusão (para não cair em pegadinha)

O que significa “100%” aqui?

Não existe uma única definição universal. Este tracker separa a campanha principal, o pós-jogo e os objetivos de colecionador. Para uma conclusão extrema, também entram formas, decoração, fitas, itens, palavras do Easy Chat, registros de batalha e tarefas diárias. A lista é uma base prática e expansível; não vou fingir que cada coordenada de item escondido e cada um dos 493 Pokémon já está descrito individualmente nesta primeira versão.

O que não dá para obter só com o meu DSi XL?

O DSi XL não se conecta diretamente a outros cartuchos para trocas sem outro console. Evoluções por troca (como Machamp, Gengar, Alakazam e Golem), Pokémon exclusivos de outras versões e alguns Pokémon que dependem de transferência ficam bloqueados sem ajuda externa. A conexão Nintendo Wi-Fi Connection oficial para DS foi encerrada em 20/05/2014; eventos de distribuição antigos não estão disponíveis pelo método original.

Eventos míticos: posso contar como legítimos?

Darkrai, Shaymin e Arceus têm conteúdo/eventos específicos que dependem de itens de evento em Pokémon Platinum. Sem um item já recebido no cartucho, distribuição oficial ativa ou método alternativo, não são obtíveis pela jogabilidade normal atual. Este tracker não recomenda códigos, save editing ou servidores não oficiais como “legítimos”.

Salvar e usar no GitHub Pages

Este é um único arquivo HTML. Salve como index.html num repositório GitHub e ative GitHub Pages em Settings → Pages → Deploy from a branch → main / root. O progresso fica no armazenamento local do navegador; não sincroniza automaticamente entre celular e PC. Use Exportar backup para guardar uma cópia.
